# بازوی بله برای بررسی نگارش پایان‌نامه و مقاله

رایگان، قاعده‌محور (بدون هوش مصنوعی پولی) و قابل‌گسترش.

## راه‌اندازی

1. در بله با `@botfather` یک بازو بسازید و توکن را بگیرید.
2. نصب و اجرا:
   ```bash
   pip install -r requirements.txt
   export BALE_TOKEN="توکن شما"
   python bot.py
   ```
3. تست بدون بازو: `python checker.py thesis.docx --mode thesis --annotate out.docx`

متغیرهای اختیاری: `MAX_FILE_MB` (۱۵)، `COOLDOWN_SEC` (۲۰)، `WORKERS` (۳)،
`BALE_API_BASE` (`https://tapi.bale.ai`)، `BALE_FILE_BASE` (آدرس دانلود فایل).

> بازو باید همیشه روشن باشد (long polling). روی کامپیوتر شخصی، VPS یا هر میزبانی که پایتون اجرا کند و به `tapi.bale.ai` دسترسی داشته باشد کار می‌کند.

## ساختار

| فایل | کار |
|---|---|
| `bot.py` | ارتباط با بله، دریافت فایل، ارسال خروجی‌ها |
| `checker.py` | موتور بررسی (تایپوگرافی، صفحه‌آرایی، ساختار، ارجاع) |
| `rules.json` | اعداد، فهرست‌ها و بخش‌های الزامی؛ **با دستورالعمل دانشگاه‌تان تنظیمش کنید** |

## افزودن قانون
- غلط رایج جدید: یک جفت در `common_mistakes`.
- واژه‌ی محاوره‌ای: به `informal_words`.
- قانون regex جدید: یک تاپل به `TEXT_RULES` در `checker.py` + عنوانش در `RULE_TITLES`.
- پروفایل دانشگاه دیگر: `rules.json` را کپی و با `checker.load_rules(path)` بارگذاری کنید.

## محدودیت‌ها
- شماره‌ی صفحه در docx ذخیره نمی‌شود؛ محل خطا با «عنوان + شماره‌ی پاراگراف» و کامنت Word نشان داده می‌شود.
- غلط‌یاب املایی کامل نیست (فقط فهرست غلط‌های رایج). پیشنهاد: افزودن دیکشنری Hunspell فارسی.
- ارجاع‌یابی APA/عددی تقریبی است.
- PDF پشتیبانی نمی‌شود.

## اجرای سریع
1. `.env.example` را کپی کنید به `.env` و توکن را بعد از `BALE_TOKEN=` بنویسید.
2. ویندوز: روی `run.bat` دوبار کلیک کنید. لینوکس/مک: `./run.sh`
3. هرگز توکن را جایی منتشر نکنید؛ اگر لو رفت در `@botfather` توکن جدید بگیرید.
